Round 1 abstract

FairDeal AI is a seller agent for small online stores. It negotiates price and bundles with AI buyer agents, keeps margin, never breaks store policy, and never says anything the store data can't back up.

The problem

Shoppers are starting to send AI agents to buy for them. Sellers built on language models are easy to exploit: they accept below-cost deals, anchor on fake budgets, obey instructions hidden in buyer messages, and deadlock.

What's new

One rule drives the design: AI reads and writes the conversation, but code decides money, because prices need guarantees a language model can't give.

A hard policy gate

Every outgoing price passes a guard that computes each product's floor from minimum margin, maximum discount and stock, always rounding up. Bundle totals are split so every unit stays above its own floor.

Offers move price, words don't

A deterministic engine concedes on a time curve, mirrors only real buyer concessions, meets a buyer holding a feasible offer halfway, and must close or walk away by round 10. Budgets, competitor quotes, deadlines, “manager approval”, spoofed seller messages and hidden prompt injections are flagged and answered politely, but pricing never reads them.

Built for machine buyers

Every offer carries an offer_id to accept by, claims citing each fact to store.csv, and structured alternatives. Replies never restate a buyer's number, and an optional LLM rewrite is discarded if it adds any unsupported number.

Proven, not claimed

A red-team suite runs 22 named attacks, each beside an honest twin making the same offers; the attacker never pays less. 200 of 200 buyer pairs with identical offers but different words got identical prices. An ablation study shows what each rule adds; it caught and removed one rule that lost late deals.

Results

200 held-out negotiations against four kinds of buyer bots, beside a naive “agreeable” seller on the same scenarios. Margin kept = (price − cost) ÷ (list − cost).

Impact

Small sellers can open their stores to AI shopping agents without risking margin or trust. It understands Indian buyers (“15k”, “1.2 lakh”, Hinglish), and a replay page shows every decision.

Cost estimate

The core path has no model calls: 0.11 ms per turn (p99 0.23 ms). Over HTTP, one process served 139 full negotiations per second, so a million negotiations take about $0.04 of server time on an AWS t3.small in Mumbai ($0.0224/hour). It ships as a Docker image with a small web API.

Build summary

A standard-library Python core, and around it: a 10-round harness, rule-based, randomised and LLM buyer bots, an independent scorer, red-team and ablation suites, a tuning script, CI with 21 tests, and agent cards.
