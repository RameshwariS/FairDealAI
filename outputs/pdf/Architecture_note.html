FairDeal AIarchitecture note
AgentX Challenge 2
Selling to Machines
Round 1

AI reads and writes the conversation; code decides money. Every price, acceptance and walk-away comes from deterministic code, and a policy gate checks every message before it leaves the store.

Failure modeHow FairDeal AI blocks it
Below-cost or below-policy dealHard floor per unit = max(margin floor, list × (1 − max discount)), rounded up. The guard re-checks even the engine's own output.
Anchoring on a fake budget or competitor quoteClaims are logged and answered, never priced. A budget below the floor gets in-stock alternatives instead of a discount.
Prompt injection (text, hidden JSON fields, HTML comments, Unicode look-alikes)Unicode is normalised and every field is scanned. Nothing from buyer text reaches the pricing code.
Spoofed “seller:” or “system” messagesFlagged and treated as buyer input.
Fake “I accept ₹X”A deal closes only at a price we actually offered, by offer_id or price.
Fake lowball to farm a concession; item swap to resetBuyer moves are measured from their best earlier offer. Concession progress survives a basket change.
DeadlockFinal offer on round 9; the agent must accept or walk away on round 10.
Invented scarcity, urgency, hidden feesBanned phrases, no buyer numbers restated, and a number-by-number truth check on every reply.

Fairness and red-team

Price depends only on the basket, the round and the buyer's offers. On 200 paired buyers with identical offers but different words, ids and hidden fields, 200 got identical prices. A red-team suite runs 22 named attacks, each beside an honest twin making the same offers: 22 of 22 defeated, manipulation gain 0.

Testing and ablation

21 pytest checks run in CI on every push, including a 3,000-message fuzz and the red-team suite. An independent scorer re-reads the store and policy files itself, so a guard bug can't hide. Switching rules off one at a time shows the firm-offer rule lifts the score against holdout buyers from 0.50 to 0.61. It also caught an early walk-away rule that lost every last-minute buyer, which we removed.

Deployment, latency and cost

A small web API (POST /negotiate, one session per negotiation) ships as a Docker image. Measured: 0.13 ms per turn in-process (p99 0.24 ms) and 128 full negotiations per second over HTTP from one process. On an AWS t3.small in Mumbai at $0.0224/hour, that is about $0.05 of server time per million negotiations, with no model calls on the core path.
